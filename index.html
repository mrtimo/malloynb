Run and share Malloy notebooks in the browser

Paste the link to a .malloynb file, or drop one here. The page loads DuckDB and the Malloy compiler in your browser, reads the notebook, and runs it. There's nothing to install and no server.

What works

  • Notebooks that use the duckdb connection with public Parquet or CSV files.
  • Data URLs must allow cross-site requests (CORS). GitHub raw files, Hugging Face and shell.duckdb.org do.
  • Relative paths like duckdb.table('data/x.parquet') and import "model.malloy" resolve against the notebook's URL.
  • You can edit and re-run cells. Edits stay in your browser until you share a link that includes them.
